import { Button } from "@devjaeyoon-design-system/react";

`Button`은 native `button` props를 유지하면서 `variant`, `size`, `loading`을 제공합니다.

<Button>저장</Button>

```tsx
import "@devjaeyoon-design-system/css";
import { Button } from "@devjaeyoon-design-system/react";

<Button size="medium" variant="primary">
  저장
</Button>;
```

`loading` 중에는 중복 제출을 막기 위해 버튼이 disabled되고 보조 기술에 busy 상태를
전달합니다. 폼 제출이 목적이면 native API와 동일하게 `type="submit"`을 명시합니다.

variant, 크기, loading/disabled 상태와 interaction은
[Storybook](https://devjaeyoon.github.io/devjaeyoon-design-system/storybook/)에서 확인합니다.
