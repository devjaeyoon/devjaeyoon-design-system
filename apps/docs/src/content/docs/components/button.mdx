import { Button } from "@devjaeyoon-design-system/react";

`Button`은 텍스트로, `IconButton`은 아이콘으로 작업을 실행합니다. 작업 영역마다 주요 행동을
명확하게 선택하세요. 화면 전체의 primary 개수를 일률적으로 제한하지는 않습니다.

<Button>저장</Button>

## 행동의 의미와 표현 선택

행동 이름은 “저장”·“삭제”처럼 실행할 작업을 설명합니다. `tone`은 위험 여부 같은 의미를,
`variant`는 강조 수준과 표현 방식을, `size`는 크기를 선택합니다.

| variant | 권장 사용 상황 | 외형 |
| --- | --- | --- |
| `primary` | 저장·분석·확인 등 주요 행동 | 브랜드색 배경 |
| `secondary` | 미리보기·불러오기 등 덜 강조하는 독립 행동 | 부드러운 중립색 배경 |
| `outline` | 취소·이전 등 주요 행동 옆의 보조 선택 | 투명 배경과 테두리 |
| `ghost` | 닫기·더 보기 등 주변 콘텐츠를 방해하지 않을 행동 | 기본 배경과 테두리 없음 |

표의 행동은 사용 상황의 예시이며 특정 variant에만 허용되는 행동은 아닙니다. 같은 “이전”
행동도 주변 콘텐츠와 강조 수준에 따라 outline이나 ghost를 선택할 수 있습니다.

삭제 등 위험한 행동은 강조 수준과 별개로 `tone="danger"`를 사용합니다. 네 variant 모두
지원하며 primary는 critical solid, secondary는 critical weak, outline·ghost는 critical
foreground를 사용합니다. 색상 외에도 “삭제”처럼 행동을 분명하게 표현하세요.

## 기본 사용과 아이콘

```tsx
import "@devjaeyoon-design-system/css";
import { Button, IconButton } from "@devjaeyoon-design-system/react";

<Button startIcon={<SaveIcon />} endIcon={<ArrowIcon />}>저장하고 계속</Button>
<Button variant="outline">취소</Button>
<Button tone="danger" variant="secondary">선택 항목 삭제</Button>
<IconButton aria-label="항목 추가" size="large"><PlusIcon /></IconButton>
```

아이콘 컴포넌트는 소비자가 제공합니다. 아이콘 라이브러리 의존성은 없습니다. `startIcon`,
`endIcon`, IconButton의 `children`은 `ReactNode`이며 아이콘은 접근성 이름에서 제외됩니다.
아이콘 슬롯에는 SVG·이미지 등 비상호작용 요소를 넣으세요. IconButton은 행동을 설명하는
문자열 `aria-label`이 필수입니다. 툴팁이나 아이콘의 title만으로 대체하지 마세요.

## 기본값과 native props

Button 기본값은 `primary / medium / default`, IconButton은 `ghost / medium / default`입니다.
둘 다 기본 `type="button"`으로 폼을 제출하지 않습니다. 제출에는 `type="submit"`을 명시하세요.
`ref`, `name`, `value`, 이벤트와 나머지 native button props를 그대로 사용할 수 있습니다.

## 크기와 배치

| size | Button 최소 높이 / IconButton 한 변 | 텍스트 | 좌우 패딩 | 아이콘 |
| --- | --- | --- | --- | --- |
| `small` | 32px | 12px | 12px | 16px |
| `medium` | 40px | 14px | 16px | 20px |
| `large` | 52px | 16px | 20px | 24px |

루트 글자 크기 16px 기준입니다. 높이·모서리·아이콘 크기는 rem이며 공통 모서리는 12px,
간격은 8px, 글꼴 두께는 label typography의 600입니다. IconButton에는 좌우 패딩 없이
정사각형 크기를 적용합니다. 모바일의 주요 조작에는 large를, 밀도 높은 도구 화면에는
small을 권장합니다. Button의 긴 텍스트는 줄바꿈하며 최소 높이 이상으로 늘어납니다.
너비와 바깥 여백은 소비자가 `className`·`style`로 결정합니다.

## 상태와 접근성

`disabled`와 `loading`은 native disabled로 실행과 Tab 접근을 차단합니다. 일반 disabled는
공통 비활성 색상, loading은 원래 variant 색상을 유지하며 hover·pressed는 적용하지 않습니다.

Button과 IconButton은 loading 중에도 행동 이름을 유지합니다. 처리 상태는 `aria-busy`와 별도
live region으로 안내합니다. `loadingLabel` 기본값은 `"처리 중"`이며
`loadingLabel="파일 업로드 중"`처럼 바꿀 수 있습니다. 이 값은 행동 이름을 대체하지 않고
`aria-describedby`에 연결된 설명으로 추가됩니다. 외부에서 전달한 설명은 유지하며, loading이
끝나면 처리 상태 설명만 연결에서 제외되고 live region의 텍스트는 비워집니다.

Button은 텍스트를 유지하고 시작 아이콘 자리에 스피너를 표시합니다. 시작 아이콘이 없으면
앞에 추가하며 끝 아이콘은 유지합니다. IconButton은 아이콘을 스피너로 교체합니다.
reduced-motion에서는 스피너가 회전하지 않습니다.

키보드 Enter·Space로 실행하고 focus-visible에는 3px 외곽선과 2px 간격을 표시합니다.
눌림 확대·축소 효과는 없습니다.

컴포넌트는 전달받은 상태를 표시하고 실행을 차단합니다. 비동기 작업의 실행, loading 해제,
성공·실패 알림은 소비자가 관리합니다.

## 스타일과 테마

서비스 색상은 semantic CSS 변수를 앱의 테마 경계 한 곳에서 설정하세요. 상태별 CSS를
복제할 필요가 없습니다. 다음 중립색 예제는 해당 컨테이너의 브랜드 버튼만 바꿉니다.
critical 토큰을 사용하는 danger와 컨테이너 밖 버튼은 유지됩니다.

```css
.service-theme {
  --djy-color-bg-brand-solid: var(--djy-color-bg-neutral-solid);
  --djy-color-bg-brand-solid-hover: var(--djy-color-bg-neutral-solid-hover);
  --djy-color-bg-brand-solid-pressed: var(--djy-color-bg-neutral-solid-pressed);
  --djy-color-fg-on-brand: var(--djy-color-fg-on-neutral);
}
```

`html`의 `data-theme="light"`, `data-theme="dark"`, 속성 없음(system) 계약을 유지합니다.
색상을 직접 정하는 서비스는 light/dark와 hover·pressed의 텍스트·아이콘·테두리·포커스 대비도
함께 검증해야 합니다. `radius-control`, `size-control-sm/md/lg` 토큰은 두 버튼이 공유하며
TextField는 별도의 외형을 사용합니다.

Tailwind와 함께 쓰는 앱은 모든 import보다 앞에서 레이어 순서를 선언하세요.

```css
@layer theme, base, djy, components, utilities;
@import "tailwindcss";
@import "@devjaeyoon-design-system/css/styles.css";
```

## 호환성과 예제

기존 Button 호출은 계속 사용할 수 있습니다. 이전 버전보다 모서리가 8→12px,
large 최소 높이가 48→52px로 바뀌고, loading은 비활성 색상 대신 원래 색상을 유지합니다.

전체 조합과 상태 전환, light/dark, 중립색 테마는
[Storybook Button](https://devjaeyoon.github.io/devjaeyoon-design-system/storybook/?path=/story/components-button--variant-tones)에서 확인합니다.
링크 버튼·토글 버튼과 서비스별 테마 패키지는 이번 API 범위에 포함하지 않습니다.
